RINGKASAN TEORI DASAR PYTHON

Materi Pengertian Coding, Fungsi Print, dan Tipe Data SMA Kelas 10

💻 1. Pengertian Coding & Python

• Coding: Menulis instruksi atau perintah yang dipahami komputer.
• Pencipta Python: Guido van Rossum (1991).
• Ekstensi File: Disimpan dengan akhiran .py.
• Komentar (#): Tanda pagar digunakan untuk catatan yang diabaikan komputer.

📢 2. Fungsi print() & Tanda Petik

• Fungsi: Menampilkan teks atau output hasil ke layar.
• Tanda Petik: Teks/kalimat WAJIB diapit tanda kutip ("..." atau '...').
• Operasi Matematika: print(5 + 5) akan menghasilkan angka 10.

🔤 3. String (str) & Integer (int)

• String (str): Tipe data teks berhuruf yang diapit tanda petik, contoh: "Jakarta".
• Integer (int): Bilangan bulat tanpa koma/pecahan, contoh: 25, 100, -5.

🔢 4. Float (float) & Boolean (bool)

• Float (float): Bilangan desimal/pecahan dengan tanda titik (.), contoh: 3.14, 7.5.
• Boolean (bool): Tipe logika dengan HANYA dua nilai: True (Benar) dan False (Salah).
• Fungsi type(): Digunakan untuk mengecek tipe data nilai.
