RINGKASAN TEORI PYTHON

Materi Teori Dasar SMA Kelas 10 (Sesuai 100% dengan 37 Soal Bank Kuis)

💻 Pengertian Coding & Pemrograman

Kunci Soal #1 & #2

Coding adalah kegiatan menulis deretan perintah atau instruksi terstruktur agar komputer dapat menjalankan tugas yang kita kehendaki. Manfaat utamanya adalah melatih logika berpikir teratur dan pemecahan masalah (problem solving).

🏷️ Variabel & Tanda Sama Dengan ( = )

Kunci Soal #3

Variabel adalah wadah penyimpanan data di memori. Pengisian nilai menggunakan operator tanda sama dengan ( = ).

skor = 100 # variabel skor diisi angka 100
nama = "Budi" # variabel nama diisi teks

📁 Ekstensi File Program (.py)

Kunci Soal #4

File program Python selalu berekstensi .py (misalnya latihan.py atau tugas.py).

latihan1.py
tugas_subway.py

#️⃣ Komentar di Python (Tanda Pagar #)

Kunci Soal #5

Tanda pagar (#) digunakan untuk catatan programmer yang tidak akan dijalankan komputer.

# Catatan program siswa
print("Hai!") # cetak Hai

🧩 Pengertian Algoritma

Kunci Soal #6

Algoritma adalah deretan langkah-langkah logis, berurutan, dan terstruktur untuk memecahkan suatu masalah.

Mulai ➔ Input Nama ➔ Lari Subway ➔ Jawab Kuis ➔ Selesai

💡 Karakteristik Utama Bahasa Python

Kunci Soal #7
1. High-Level Language: Tata bahasanya sangat bersih, sederhana, dan mudah dipahami karena mirip bahasa Inggris sehari-hari.
2. Case-Sensitive: Huruf besar/kecil berpengaruh. print() benar, sedangkan Print() akan Error.

📢 Fungsi Perintah print() & Output Layar

Kunci Soal #8

Fungsi print() bertugas menampilkan atau mencetak teks, angka, dan output hasil perhitungan ke layar konsol monitor.

( ) Tanda Kurung Biasa

Kunci Soal #10

Pemanggilan fungsi di Python selalu menggunakan sepasang tanda kurung biasa: ( ), bukan [ ] atau { }.

print("Halo") ✓ Benar
print["Halo"] ✕ Salah

"..." Tanda Petik untuk Teks

Kunci Soal #9 & #11

Teks kata atau kalimat WAJIB diapit tanda petik dua ("...") atau petik satu ('...').

print("Selamat Pagi!") ➔ Output: Selamat Pagi!
print('Aku Siswa SMA') ➔ Output: Aku Siswa SMA

🧮 Operasi Matematika dalam print() (Tanpa Petik)

Kunci Soal #12, #13, #14

Jika angka ditulis tanpa tanda petik, Python akan langsung menghitung operasi matematikanya:

# Penjumlahan Soal #12
print(5 + 5)
# Output: 10
# Pengurangan Soal #13
print(10 - 3)
# Output: 7
# Perkalian (*) Soal #14
print(4 * 2)
# Output: 8

⚠️ Perbedaan Sangat Penting: Angka Berkutip vs Tanpa Kutip!

Kunci Soal #15
print("10 + 5")
➔ Karena ada tanda petik, dicetak persis sebagai teks tulisan apa adanya: 10 + 5.
print(10 + 5)
➔ Karena tanpa tanda petik, komputer menghitung hasilnya: 15.
Bolehkah mencetak angka langsung tanpa petik? Ya! Contoh print(100) akan langsung mencetak angka 100 ke layar tanpa error.
Kunci Soal #16

🔤 4 Tipe Data Dasar Python & Fungsi type()

Kunci Soal #17 s.d. #37

Tipe data menentukan jenis nilai yang disimpan di dalam program. Ada 4 tipe data utama yang wajib dikuasai siswa kelas 10:

🔤 1. String (str) - Teks
Soal #17–#21

Tipe data untuk menyimpan teks kata/kalimat. Ciri khasnya wajib diapit tanda petik ("..." atau '...'). Termasuk angka yang diapit kutip!

kata = "Indonesia" # Soal #18
kota = "Jakarta" # Soal #20
nomor = "99" # tetap String karena ada petik! (Soal #21)
🔢 2. Integer (int) - Bilangan Bulat
Soal #22–#26

Tipe data untuk bilangan bulat tanpa koma/desimal. Mencakup bilangan positif, nol, dan negatif.

nilai = 25 # Soal #23
umur = 16 # Soal #24
pensil = 5 # Soal #26
suhu = -10 # bulat negatif tetap int (Soal #25)
📐 3. Float (float) - Angka Desimal
Soal #27–#31

Tipe data untuk angka desimal atau pecahan. Di Python pemisah desimal menggunakan tanda titik (.), bukan koma.

pi = 3.14 # Soal #28
tinggi = 168.5 # Soal #29
skor = 0.5 # Soal #31 (titik pemisah, Soal #30)
⚖️ 4. Boolean (bool) - Nilai Logika
Soal #32–#36

Tipe data logika yang HANYA memiliki 2 nilai: True (Benar / Ya) dan False (Salah / Tidak). Huruf awal wajib kapital.

True ➔ Benar / Ya # Soal #33
False ➔ Salah / Tidak # Soal #34
lulus = True # Soal #35
menyala = False # Soal #36

🔍 Perintah type() untuk Mengecek Tipe Data

Kunci Soal #37

Gunakan fungsi bawaan type() untuk mengetahui jenis tipe data dari sebuah nilai atau variabel di Python.

print(type("Halo")) ➔ <class 'str'> (String)
print(type(10)) ➔ <class 'int'> (Integer)
print(type(3.14)) ➔ <class 'float'> (Float)
print(type(True)) ➔ <class 'bool'> (Boolean)
